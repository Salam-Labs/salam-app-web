# Version 2.0.6 🎉🎉

## Download

- [Apple App Store](https://apps.apple.com/app/id1629159763)

## All Platforms

This release expands key Salam App modules and improves the reliability of Quran reading and audio, prayer times, location, reminders, backups, onboarding, and everyday app performance.

- Added a new Tajweed Color Guide to the Quran module, with explanations of the reader’s colors and pronunciation rules.
- Improved Quran text display by fixing clipped Arabic vowel marks, overlapping stop signs, IndoPak letter connections, and word-by-word translation alignment.
- Improved Quran audio with smoother verse highlighting, more accurate progress, better reciter switching, safer downloads, and correct surah and verse details in device media controls.
- Expanded the Dhikr & Dua module so dhikr can be added directly from categories to My Lists, with the option to create a new list, edit personal goals, and use improved counter controls.
- Improved automatic location updates and added clearer privacy, success, and failure information for precise and manual location options.
- Added regional prayer calculation methods for Morocco, Tunisia, Jordan, and Portugal, plus the Jafari method.
- Fixed automatic prayer-method matching and added missing prayer-time defaults for Brunei, Comoros, Kosovo, and Mali.
- Improved prayer schedule and reminder updates to reduce the chance of an alert being missed when settings change.
- Clarified that Sunrise marks the end of Fajr time and is not a prayer.
- Improved reminders so cards move in the same direction as the user’s swipe.
- Improved Salam App Cloud backup so temporary setup failures can be retried.
- Refreshed onboarding explanations, language ordering, translation notices, Indonesian wording, and the displayed Salam community count.
- Made the Home screen smoother when using glass effects and improved the appearance of the bottom navigation bar.
- Improved Home screen efficiency, Quran reader performance, Hadith loading, reminders, local databases, and online-status updates.

## iOS

- Improved iPhone prayer-time widget calculations so they stay consistent with settings saved in the app.
- Improved Apple Watch prayer-data syncing for more consistent and up-to-date information.
- Updated iOS platform support and related dependencies for better compatibility and stability.

## Android

- Fixed the white flash that could appear when opening modules.
- Fixed Athan playback by playing it directly through the app instead of relying on Android notification sounds, making full playback more dependable across different devices.
- Added a Stop Athan control to the prayer notification.
- Improved Android prayer-notification scheduling so updated alerts are prepared before old ones are removed, reducing the chance of missed notifications after setting changes, failures, device restarts, or app updates.
- Improved Android prayer-widget calculations and fixed the widget refresh button.
- Added optional IP-based location for estimating your area without device-location permission, with clear privacy and accuracy information.
- Added clearer guidance when the Qibla compass is unavailable while using approximate IP location.
- Added a location fallback for Android devices where Google location services are missing or unreliable, including some Huawei devices.
- Improved bottom navigation spacing around Android system controls.
