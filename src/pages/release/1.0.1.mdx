# Version 1.0.1 🎉🎉

## New Features ✨✨

- Prayer screen updates, you can now directly change settings without going to app settings.
- Added home screen widget.
- Prayer settings auto detection has been fixed for users in the UK/Hong Kong/and other regions.
- Rashidun Caliphate theme has been updated. The flag design has changed. You can now tap on a button to read about history of the Rashidun Caliphate.
- About screen in settings now has acknowledgements section.
- We are now using Canny to track user feedback and roadmap. Visit salam-app.canny.io.
- For Android users, Qur'an search now doesn't lag.
- Navigating to Qur'an reader from last read, quick-links and search now always navigates to verse by verse reader, due to scrolling taking so much time.
- Added transliteration switch in global app settings.

## Other Changes 🚀🚀

- Other fixes and improvements.
