# Version 1.2.0 🎉🎉

Introducing a new design for the home screen widget! This update also includes various fixes and improvements.

## New Features ✨✨

- Prayer time Auto Detect has been improved! New calculation methods have also been added.
- Weekly prayer tracker stats.
- Home screen widget redesign. (Android Only)
- Salam App will now launch on Prayer screen by default.
- Prayer tracker stats graphs will refresh automatically.
- Network based location detection. (Android Only)
- Prayer tracker checkmark for ticks (easier to understand).
- More Hadith and Quran verses for daily reminder.

## Bug Fixes 🛠️🛠️

- App not launching from home screen widget.
- Prayer tracker stats will not show prayer missed due to menses.
- Prayer calculation setting reset on app launch.
- Prayer calculation issues (i.e 12am Isha).
- Compass issues.
- Calendar issues.
- Asma Al-Husna issues.
- Quran list view scroll.
- Daily reminder will only pop up if notification setting is on.

## Other Changes 🚀🚀

- The countdown on the Prayer screen will now update every second.
- The Home screen Quran Reminder has been replaced with Daily Reminders.
- The Classic theme has been renamed to Salam App Alpha.
- Other fixes and improvements.
