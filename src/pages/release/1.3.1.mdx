# Version 1.3.1 🎉🎉

## New Features :sparkles::sparkles:
- Added option to add custom dhikr to the custom dhikr list  
- Added "Go to Verse" option in Tafsir and Verse mode in the Quran  
- Added online user count on the home screen showing the number of users currently on Salam App  
- Introduced custom late prayer reminder (instead of the fixed 30-minute reminder)  

## Bug Fixes :tools::tools:
- Fixed Ramadan countdown ring issue  
- Fixed menses tracker to stay enabled until manually disabled  
- Adjusted custom dhikr list progress bar color  
- Improved backup and restore functionality  
- The countdown timer in the Prayer tab now updates every 5 seconds (again) to address potential performance issues.
- Minor bug fixes

## iOS Specific Updates
- iOS legacy medium home widget is back along with 2 new lock screen widgets  
- Fixed Hijri date for iOS Home screen widget  

## Android Specific Updates
- Added Smaller widget for Android home screen  
- Fixed Hijri date for Android Home screen widget  
- Fixed Android 13+ notification issue
